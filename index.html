1. Introduction & Core Concepts

Instruction: Read the simple definitions below. Computer scientists have proven that any program in the world can be written using just these three basic building blocks.

Every program you write controls the flow of data. To make a program do what you want, you must combine sequence, selection, and iteration correctly.

💡 Key Definitions for Your Exam

Sequence: Code runs line-by-line, from top to bottom, in the exact order it is written.

Selection: The program checks a condition (like an if statement). If the condition is true, it takes one path; if it is false, it takes another.

Count-Controlled Iteration: A loop that repeats code a specific, set number of times (like a for loop) before stopping.

2. Python Code Examples

Instruction: Look closely at how these look in actual Python code. Remember that exact spelling and proper indentation are vital to avoid syntax errors.

A. Sequence

Lines of code execute one after the other. Line 3 cannot happen until Line 1 and 2 finish.

x = 10
y = 5
total = x + y
print(total)
B. Selection (if-elif-else)

The program chooses which branch to run based on the score value.

score = 85
if score >= 90:
    print("A* Grade")
elif score >= 80:
    print("A Grade")
else:
    print("Pass")
C. Selection (match-case)

Newer Python syntax! It matches a variable against different cases. The wildcard `_` acts like an "else" if nothing else matches.

status = 404
match status:
    case 200:
        print("Success")
    case 404:
        print("Not Found")
    case _:
        print("Unknown Error")
D. Count-Controlled Iteration

A loop that counts up or down. Python uses range(start, stop, step) to tell the loop how many times to run.

# range(start, stop_before, step)
for i in range(2, 11, 2):
    print(i)
# This will count: 2, 4, 6, 8, 10
