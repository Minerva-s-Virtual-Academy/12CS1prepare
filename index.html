1. Introduction & Core Concepts

Instruction: Read the foundational architectural concepts below. Pay strict attention to the structural differences between iteration and selection structures.

According to the Böhm-Jacopini theorem, any computable algorithm can be expressed using exactly three structural configurations: sequence, selection, and iteration. Mastery of these is vital for optimizing time and space complexity variables at A-Level standard.

💡 Key Structural Definitions

Sequence: Statements are executed consecutively, precisely in the linear order they are written down, with the program counter incrementing line-by-line.

Selection: A logical gateway condition evaluates to True or False (Boolean), forcing the program control flow down branching execution trajectories.

Count-Controlled Iteration: A processing block that executes a precise, predetermined number of loops using an incrementing or decrementing loop index variable tracking toward a boundary terminate state.

2. Technical Deep Dive (Python Implementations)

Instruction: Examine how Python shifts structural behavior through syntax formatting. Note that keyword case sensitivity is highly penalized in exam modules.

A. Sequence Control

Data states are modified predictably. Output variables are strictly bound by historical inputs upstream.

x = 10
y = 5
total = x + y
print(total)
B. Selection (if-elif-else)

Uses logical comparison branches. Indentation defines the execution block scope cleanly.

score = 85
if score >= 90:
    print("A* Grade")
elif score >= 80:
    print("A Grade")
else:
    print("Pass")
C. Structural Selection Match

Introduced in modern Python. Evaluates structural patterns using a streamlined pattern-matching pipeline. The wildcard case `_` handles fall-throughs.

status = 404
match status:
    case 200:
        print("Success")
    case 404:
        print("Not Found")
    case _:
        print("Unknown Error")
D. Count-Controlled Iteration

The range() object instantiates step bounds. Perfect for structured algorithmic traversal parameters.

# range(start, stop_exclusive, step)
for i in range(2, 11, 2):
    print(f"Index is {i}")
# Generates index states: 2, 4, 6, 8, 10
